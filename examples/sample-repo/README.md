# Sample Shop

A tiny multi-language repository used to test Codebase Atlas.

- `main.py` prints an inventory stock report (Python, package `inventory/`).
- `web/` is a TypeScript cart; the entry point is `web/src/index.ts`.
- `go/` is a Go shipping-rate quoter; the entry point is `go/cmd/shipper/main.go`.

Run the report with `python main.py data/items.json`.
